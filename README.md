## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` is standard-library only: it writes the finished pitch to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, verifies it is 1–220 characters,
and exits 0.
